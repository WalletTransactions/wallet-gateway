# Design

## Context

Таблица маршрутов гейтвея жёсткая: пять префиксов API, адреса апстримов обязательны и
проверяются при старте. JWT-гейт уже закрывает `/api/*` и сверяет `aud` с адресатом
маршрута. Собственные пути гейтвея (`/docs`, `/openapi.yaml`, …) не проксируются.
Мотивация — в proposal.md.

## Goals / Non-Goals

**Goals:**
- Маршрут `/api/docs/` → wallet-docs с тем же гейтом, что у `/api/ai/`.
- Гейтвей без wallet-docs работает как раньше и отвечает на `/api/docs/*` одинаково и предсказуемо.

**Non-Goals:**
- Роли и уровень видимости: их проверяет wallet-docs по claim'ам `role` и `platform`.
- Маршрут заливки индекса и сводка версий для wallet-docs (Jenkins ходит напрямую по сети контура).

## Decisions

**D1. Адрес апстрима необязателен.** Единственное исключение из правила «пустой адрес —
выход с кодом 1». Причина — модульность фичи: контур без wallet-docs не должен падать.
Альтернатива «обязательный адрес» отвергнута: тогда любой контур без docs требовал бы
фиктивного значения. Альтернатива «молча отдать в wallet-api» отвергнута: wallet-api
ответил бы 404 на неизвестный путь, а клиенту нужен один и тот же ответ.

**D2. Без апстрима — `404` до проверки токена.** Клиент скрывает раздел при любом не-200
на `/api/docs/status` (и `404`, и `502`), поэтому токен проверять незачем, а анонимный
запрос не должен выдавать `401` вместо «модуля нет».

**D3. Тот же гейт, что у `/api/ai/`.** Префикс `/api/docs/` стоит перед `/api/`, `aud` —
`wallet-docs`. Токены, выданные до выката google-auth `docs-audience`, получат `401` — это
нормально: клиент перепроверит статус после обновления токена (15 минут).

**D4. Порядок выкатки.** google-auth (`docs-audience`, additive) → wallet-docs → этот
change и `WALLET_DOCS_URL` → клиенты. До появления сервиса `WALLET_DOCS_URL` пуст.

**Правки вне wallet-gateway:** google-auth (`aud`), wallet-infra (переменная окружения).

## Risks / Trade-offs

- [Гейтвей и wallet-docs выкатили в обратном порядке] → `404` до задания URL и `502`
  после: оба скрывают раздел в клиентах.
- [Токен без `wallet-docs` в `aud` у только что вошедшего пользователя] → невозможно:
  `docs-audience` выкатывается первым; старые токены живут максимум 15 минут.
- [Путь `/api/docs` без слеша уходит в wallet-api] → задокументировано сценарием, клиент
  всегда использует путь со слешем после префикса.
