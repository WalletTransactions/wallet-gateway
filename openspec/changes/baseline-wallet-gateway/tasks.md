# Tasks

Изменение не меняет код: задачи — только сверка спецификаций с кодом и живым
стеком. Найденное несоответствие исправляется в спецификации, если неточна она,
или записывается в «Наблюдения» `design.md`, если расходится документ или код
ведёт себя неожиданно. Код в рамках этого изменения не правится.

Проверка — `curl` через гейтвей (`http://localhost:8090`). Действительный токен —
из cookie `session` браузерной сессии или `Authorization: Bearer`; токены с
другим `aud`/без `aud` — подписать нельзя, поэтому такие сценарии проверяются
токеном бота (`aud` без `google-auth`) или отмечаются как проверенные по коду.
Сценарии с остановленным апстримом, занятым портом и отсутствующей переменной —
на отдельном контейнере гейтвея (`docker run` образа `servers-wallet-gateway` с
другим портом и своим окружением), рабочий контейнер не трогается.

## 2. Сверка по capability

Для каждой спецификации: каждый сценарий сопоставить с местом в коде и прогнать
`curl`; коды, заголовки и тексты ответов гейтвея совпадают дословно.

- [ ] 2.1 `request-routing` — `find_route`, `register_routes`, `main()`; проверка — запросы на каждый префикс приходят в свой апстрим (по `request_finished` в журнале апстрима с тем же `X-Trace-Id`), `/api` без слеша и `POST /healthz` уходят в wallet-web, `HEAD /` и `TRACE /`, `502` и отсутствующая переменная — на отдельном контейнере
- [ ] 2.2 `edge-jwt-gate` — `has_valid_token`, `handle_pre_routing`, `jwks::Cache`, `jwt_claims::check`; проверка — без токена, с битым токеном, с cookie и с `Bearer`, токен бота на `/sync/push` и на `/api/reports/*`, текст `401`, рост `jwt_claims_total`, строка `jwt_rejected` в журнале
- [ ] 2.3 `proxy-forwarding` — `proxy_request`, `ensure_trace_id`; проверка — query и тело доходят до апстрима, апстрим получает `Accept-Encoding: identity` и `X-Forwarded-Host` (журнал или отладочный апстрим), `X-Trace-Id` в ответе, два `Set-Cookie` после входа, `Content-Encoding: gzip` на `/app.js`
- [ ] 2.4 `api-docs` — `docs.cpp`; проверка — `/docs` со списком из пяти спек, `/openapi.yaml`, `/openapi/<name>.yaml` для всех четырёх апстримов с `servers: /`, `404` на неизвестное имя, `502` при остановленном апстриме (отдельный контейнер), `/vendor/swagger-ui/swagger-ui-bundle.js`
- [ ] 2.5 `gateway-ops` — `/healthz`, `/version`, `/metrics`, логгер, `Containerfile`, CI; проверка — ответы трёх ручек, отсутствие `/healthz` в журнале, обрезка тела в debug-строке, `docker build` с `--build-arg GIT_COMMIT` даёт хэш в `/version`, занятый порт — на отдельном контейнере
